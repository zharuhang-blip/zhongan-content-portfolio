车小圈出行记 · 选题策划摘要

作品集脱敏版 · 展示选题体系 / 风格判断 / 优先级规划能力

我的工作重点：不是先录音，而是先把栏目「听什么、怎么讲、先做哪几集」想清楚——建立可执行的选题库与叙事方法。

1. 栏目定位（构思）

儿童出行安全播客。角色体系：车小圈（安全小卫士）+ 朵朵（好奇）+ 胖墩（懵懂）。用故事代入，不用说教独白。

2. 选题结构（25 个）

大类数量说明
出行安全类10道路交通、极端天气、特殊场景
陌生人·自我保护类8拐骗防范、走失应对、网络安全
交通工具认知类7盲区、站台、应急车辆让行

3. 内容风格判断（总结）

故事代入 角色互动 口诀童谣 问题导入 家长共听

明确淘汰说教式讲解、纯知识灌输、单人独白——以保证完播与记忆点。

4. 优先级与落地

  • 按热度/家长焦虑/政策节点排出「立即制作」批次（如商场走失、接送防范、校车安全、汽车盲区）。
  • 已产出示例脚本：《马路上看到事故怎么办？》等，沉淀安全三步口诀。
  • 同步维护待开发清单：总数 25，已完成约 10，待开发约 15，可持续排期。

5. 能力证明（一句话）

能把儿童安全内容从「灵感」做成「选题库 + 风格标准 + 优先级排期 + 可拍脚本」的完整策划闭环。
